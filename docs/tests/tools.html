🏆 Winnaars

5 modellen scoren 4/4

GPT-OSS-120B, Nemotron-3-Super, Nemotron-3.5-Lightning en beide Qwen3.8-27B-varianten voltooien alle vier scenario's correct.

Belangrijkste bevinding: llama.cpp's tool-parser wijst de tool-output van Llama-3.3 af met een HTTP 500 ("does not match the expected peg-native format"). Dit is een build/harness-beperking, niet per se een tekortkoming van het model.

Wat onthult deze test?

--jinja is geen optie, het is verplicht

Zonder de --jinja server-flag faalt tool-calling bij vrijwel alle modellen. Dit is een veelvoorkomende valkuil in productie: tool-calling werkt perfect in de documentatie, maar in de praktijk ontbreekt de flag en faalt alles zonder duidelijke foutmelding.

Methodologie

4 scenario's: enkelvoudige tool-call, geketende calls (weer → rekenen), irrelevante tool-vermijding (Parijs-vraag), en conditionele multi-tool logica (klant opzoeken → conditioneel weer). Scoring valideert tool-call traces op juiste functienaam, parameters, en volgorde.

python3 scripts/bench_tools.py <port> <model_name>

Server starten met: llama-server ... --jinja
